# Model-evaluation tables

This folder contains the aggregate evidence retained from temporal validation,
the locked test and the approved sensitivity checks. The main tables cover:

- audited temporal populations and leakage checks
- validation summaries for the 16 candidate specifications
- locked-test performance, calibration and monitoring capacity
- controlled feature ablations
- model performance by vintage and supported segment
- feature importance and bounded partial-dependence results

Detailed tuning logs, fitted model files, borrower-level predictions and
individual risk scores are not included in the public repository.
